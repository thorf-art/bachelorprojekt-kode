## Sådan køres koden

1. Klik på den grønne `Code`-knap på GitHub og vælg `Download ZIP`.
2. Pak ZIP-filen ud.
3. Åbn den inderste mappe `bachelorprojekt-kode-main` i RStudio. Det er mappen, der indeholder:
   - `Reeldatakode.R`
   - `Simulationskode.R`
   - `data`-mappen
4. Sæt working directory til denne mappe i RStudio:
   `Session -> Set Working Directory -> Choose Directory...`
5. Kør `Reeldatakode.R` for den empiriske analyse.
6. Kør `Simulationskode.R` for simulationsanalysen.
