## Sådan køres koden

1. Klik på den grønne `Code`-knap på GitHub og vælg `Download ZIP`.
2. Pak ZIP-filen ud.
3. Åbn RStudio.
4. Sæt working directory til den inderste mappe `bachelorprojekt-kode-main` via:
   `Session -> Set Working Directory -> Choose Directory...`

   Den rigtige mappe er den, der indeholder:
   - `Reeldatakode.R`
   - `Simulationskode.R`
   - `data`-mappen

5. Åbn og kør `Reeldatakode.R` for den empiriske analyse.
6. Åbn og kør `Simulationskode.R` for simulationsanalysen.
